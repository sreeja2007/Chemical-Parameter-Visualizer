## ⚡ Quick Start (5 Minutes)

### Windows Users - Easiest Method

1. **Start Backend**
   - Double-click: `start_backend.bat`
   - Wait for "Starting development server..."

2. **Start Web App**
   - Double-click: `start_frontend.bat`
   - Browser opens automatically at http://localhost:3000

3. **Start Desktop App**
   - Double-click: `start_desktop.bat`
   - Desktop window opens

### First Time Setup

1. **Register Account**
   - Open web browser to http://localhost:3000
   - Click "Need an account? Register"
   - Enter username and password
   - Click "Register"

2. **Upload Sample Data**
   - Click "Upload CSV" button
   - Select `sample_data.csv` from project root
   - Wait for success message

3. **View Dashboard**
   - See 4 KPI cards with metrics
   - View 3 charts (Pie, Bar, Line)
   - Click "Download PDF Report" to get report

4. **Try Desktop App**
   - Login with same credentials
   - Upload CSV or view existing data
   - See same charts as web app

## 🆘 Need Help?

### Common Issues

**Backend won't start?**
- Check Python version: `python --version`
- Install dependencies: `pip install -r backend/requirements.txt`

**Frontend won't start?**
- Check Node version: `node --version`
- Install dependencies: `npm install` in frontend folder

**Desktop app won't start?**
- Activate virtual environment
- Install PyQt5: `pip install PyQt5`

**More help?**
- Check SETUP_GUIDE.md Troubleshooting section
